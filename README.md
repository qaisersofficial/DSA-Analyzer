# DSA Analyzer

A menu-driven C++ application for analyzing Data Structures and Algorithms.

## Project Overview

This project is designed to implement and analyze various linear and non-linear data structures and algorithms using Object-Oriented Programming (OOP) principles.

## Module Hierarchy

### Core Module
- Application
- DataManager
- PerformanceAnalyzer
- Comparator

### Linear Data Structures
- **Arrays**
  - Sorting: Bubble, Selection, Insertion, Merge, Quick, Heap, Shell
  - Searching: Linear, Iterative Binary, Recursive Binary
- **Linked Lists**
  - Singly, Doubly, Circular

### Non-Linear Data Structures
- **Trees**
  - Binary Tree
  - BST
  - AVL Tree
  - Min Heap and Max Heap
- **Graphs**
  - Adjacency Matrix
  - Adjacency List
  - Traversal: BFS, DFS (using custom ArrayQueue and ArrayStack)

## Repository Structure
- `src/core/`: Core application logic
- `src/linear/`: Linear data structures (Arrays, Linked Lists)
- `src/nonlinear/`: Non-linear data structures (Trees, Graphs)
- `tests/`: Unit tests
- `results/`: Analysis results and charts
- `docs/`: Project documentation
